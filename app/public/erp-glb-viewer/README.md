# ERP GLB viewer browser build

These are the browser assets served by the ERP demo. The host serves GLB
bytes; rendering and view-only model actions run in the browser. The editable
source, tests, and build instructions are in
`app/vendor/erp-glb-viewer-source/`. The same source is available as
`app/vendor/erp-glb-viewer-source.zip` for download from the demo.

The viewer is AGPL-3.0-or-later (`LICENSE.txt`). Its bundled three.js r160
code has a separate MIT notice in `THIRD-PARTY-LICENSES.txt`. Keep the
matching source, notices, and source download with any public or hosted
derivative. Do not edit this generated build in place; change the editable
source, rebuild, and compare its output before release.
